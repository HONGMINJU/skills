빈 양식이다. 실제 과제 작업공간의 사본에서만 채운다. 이 파일은 자동 저장 장치나 완료 증거가 아니다.

## 세션 정보

- 과제명: 미확인
- 현재 AI 허용 단계와 확인 근거: 미확인
- 실제 작업 폴더 / 적용 지침: 미확인
- 실제 시작 시각 / 마감 / 시간대: 미확인

- 목표 한 문장: MISSION 작성 후 짧게 요약

## 현재 확인된 사실

- 실제 동작하는 범위: 아직 확인하지 않음
- 가장 큰 위험 또는 막힘: 아직 확인하지 않음
- 사용자 답변이 필요한 질문: 없음이 확인된 것이 아님. MISSION의 Q 항목 확인
- 관련 검증 상태와 근거: 아직 실행하지 않음
- 현재 코드 기준점 / 미반영 변경: 미확인
