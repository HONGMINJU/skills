# 구현 설명·실행 인계

빈 양식이다. AI 사용이 허용된 과제 단계에서, 제출물 확정 전에 작성한다. 후속 평가 문항의 예상 답안이나 암기 대본을 만드는 문서가 아니다.

## 무엇을 해결했는가

- 대상 사용자와 문제: MISSION 참조
- 실제 완료한 범위와 확인 근거:
- 미완료·미검증 범위:

## 어떻게 사용하는가

- 실행 위치·필요한 기존 의존성:
- 실제 확인한 실행 명령:
- 입력 파일·형식·조건:
- 대표 사용 순서와 출력 위치:
- 오류가 날 때 확인할 항목·허용된 대체 방법:

README 등 지정 실행 문서가 있으면 그 위치를 연결한다. 시험 외부로 배포하거나 제출했다고 주장하지 않는다.

| 단계 | 실제 파일·함수 | 입력 → 처리 → 출력 | 중요한 규칙·한계 |
| --- | --- | --- | --- |

## 왜 이렇게 만들었는가

중요한 선택과 포기한 대안을 DECISIONS의 실제 항목에 연결한다. 기록에 없는 결정을 사용자가 했다고 쓰지 않는다.

## 어디까지 믿을 수 있는가

- 핵심 검증 결과와 EVIDENCE ID:
- 데이터·계산·모델의 적용 조건:
- 실패 조건·알려진 한계·남은 위험:
- 실제 측정하지 않은 효과나 성능: 미측정으로 표시

## 선택: 설명 연습 이어가기

연습을 요청했고 세션을 이어갈 기록이 필요할 때만 작업 사본에 작성한다. 질문 하나씩 사용자 답변을 기다리며, 전체 대화·완성 답안·예상 점수는 기록하지 않는다.

| 연습 주제 | 실제 코드·결정·증거 위치 | 답변 대기 / 재설명 필요 / 해당 주제 재설명 확인 | 다시 확인할 개념·다음 질문의 초점 |
| --- | --- | --- | --- |

한 주제의 재설명 확인은 전체 이해나 테스트·업무 수용 완료가 아니다. 제출물 확정 이후에는 연습을 재개하지 않는다.

## 제출 전 확인

| 확인 항목 | 근거·실제 파일 | 상태·남은 조치 |
| --- | --- | --- |
| 공식 필수 파일·형식 | | 미확인 |
| 필수 요구와 구현·검증 대응 | | 미확인 |
| 설명된 실행법으로 핵심 경로 실행 | | 미확인 |
| 파일 저장·제출 대상·불필요한 민감정보 | | 미확인 |
| 필요한 사용자 수동 화면 확인 | | 미확인 |

제출물 확정은 참가자가 플랫폼에서 직접 한다. 이 문서를 작성하거나 검사 명령이 성공한 것이 제출 완료를 뜻하지 않는다. 확정 이후에는 과제 수정과 AI 설명·답안 지원을 중단하고 플랫폼 안내를 따른다.
