# 질문과 답변

빈 양식이다. 실제 과제 작업공간의 QNA.md 또는 기존 지정 Q&A 문서에서 사용한다. 이 공개 원본에는 실제 질문·답변을 적지 않는다.

에이전트는 질문이 생기면 Q ID별 블록을 만들고 Q를 작성한 뒤 사용자에게 알려준다. 사용자는 A에 실제 답변을 적고 저장한 뒤 "답변 적었어"라고 알리면 된다. 에이전트는 답변을 읽고 반영여부를 갱신한다. 파일 감시나 메신저 자동 전송 기능은 아니다.

아래 빈 블록은 질문이 생겼을 때 채운다. 새 질문은 다음 ID로 같은 세 필드만 추가한다. Q에는 그대로 전달할 질문을 쓰고 A는 답변이 올 때까지 비운다. 사용자 답변과 기존 기록은 덮어쓰지 않는다. 답변을 정정할 때는 이전 내용을 지우지 않고 정정 내용을 덧붙인다.

반영여부 예시: 답변 대기 / 답변 확인·미반영 / 재질문 필요 / 반영 중 / 반영됨·검증 대기 / 반영 완료·범위·근거 위치 / 영향 없음·이유.

답변 수신과 반영·검증 완료는 다르다. 현재 요청이 요구 정리·설계까지라면 그 범위의 완료만 표시하고 구현 완료로 확대하지 않는다. 기존 내용이 맞아 변경이 필요 없으면 확인 근거와 함께 영향 없음으로 기록한다. 요구·해석·결정·실행 근거의 상세 내용은 기존 작업 기록에 Q ID로 연결한다. 공식 지시와 충돌하거나 답변이 모호하면 해당 부분만 다시 확인한다.
